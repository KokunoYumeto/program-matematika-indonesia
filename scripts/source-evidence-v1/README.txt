SOURCE-USE ADAPTER — INTEGRATED CONSUMER

The three Python files are byte-preserving imports of the existing manager's
SOURCE-USE-20261003 R2 adapter, checked against MANIFEST_R2.json. They allocate
no global tags or bibliography keys and modify no native mathematical records.
The adapter's original implementation provenance remains in its output.

Run with Python 3.9+ and -B. No external packages or network are needed:
  python -B project_evidence.py <explicit-inputs.json> --output <private-output>
  python -B project_evidence.py <explicit-inputs.json> --output <private-output> --check
  python -B project_evidence.py <explicit-inputs.json> --result <native-result-id>
  python -B project_evidence.py <explicit-inputs.json> --source <sha256>

freeze_inputs.py can create a new dated snapshot from explicitly supplied core
and advanced trees. It refuses overwrite. Preserve old input/validation pairs.
Do not freeze private advanced material into docs, public, or a release archive.

The bilingual explorer is generated by scripts/build-source-evidence-explorer.mjs
and linked from the existing Indonesian/English course interface. Open its HTML
and explicitly select projection.json. It runs without a server, never uploads
the selection, and never persists it in browser storage. Source/result lookup
works in both directions. Full inherited conditions, revision states, source
roles, native records and existing proof locators remain available.

An optional existing sources.jsonl may be selected; keys are resolved only by
declared exact file hashes, with absent/ambiguous matches shown explicitly.
This does not allocate a second registry, establish source consultation, or
convert a content fingerprint into a bibliographic work/version identity.

Browser checks establish structure, counts and reference consistency, not full
derivation or mathematical correctness. Run the Python replay for derivation.
Snapshots describe their recorded observations, never a live course census.
English evidence remains labelled English in the Indonesian interface.

No actual private snapshot or registry is distributed with the public explorer.
The interface and integration work is AI-produced, without claimed human review.
Do not relabel inherited source authorship or historic model records.

Standalone reproduction after unzipping: node scripts/build-source-evidence-explorer.mjs
Check without rewriting: node scripts/build-source-evidence-explorer.mjs --check
Repackage: python -B scripts/package-source-evidence-explorer.py
Recheck archive: python -B scripts/package-source-evidence-explorer.py --check
