Skema backend modular v2.3

Batas cakupan: paket konformansi lama v0.1.1 hanya mencakup A00 + O001. Adapter jalur B10 v0.2.0 mencakup B10 saja dan mempertahankan backend native pemilik secara zero-copy. Kedua bukti ini tidak menyatakan konformansi agregat untuk 40 peran kurikulum. Pelajar tetap masuk melalui situs belajar, bukan melalui berkas JSON.

Skema paket v0.1.1 yang diterima

Empat berkas berikut adalah salinan bita-persis dari anggota schema/ dalam arsip rilis v0.1.1 dan merupakan alamat kanonik pada $id masing-masing.

  • Deklarasi kapabilitas v0.1.0
  • Manifest konformansi v0.1.0
  • Lintas-jalan namespace v0.1.0
  • Indeks status terjemahan v0.1.0

Skema generik adapter jalur 2.3.1 — diterima untuk B10

Enam skema berikut bersifat netral-korpus dan memvalidasi adapter B10 v0.2.0. Adapter itu menghubungkan 161 unit, 284 relasi, 161 dokumen pencarian metadata, status terjemahan berbukti, hak, aksesibilitas, dan lintas-jalan namespace tanpa menyalin isi buku. Semua tabel JSONL memiliki proyeksi CSV lossless.

  • Manifest adapter jalur v2.3.1
  • Deklarasi kapabilitas v0.2
  • Lintas-jalan namespace v0.2
  • Indeks status terjemahan v0.2
  • Manifest proyeksi CSV v0.2
  • Deklarasi cakupan v0.2
