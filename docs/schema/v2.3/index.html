Skema backend modular v2.3

Batas cakupan: paket konformansi lama v0.1.1 hanya mencakup A00 + O001. Adapter B10 v0.2.0, D60 v0.1.0, dan D110 v0.1.0 masing-masing mencakup satu jalur dan mempertahankan backend native pemilik secara zero-copy. Keempat bukti A00, B10, D60, dan D110 tidak menyatakan konformansi untuk 36 peran lain. Pelajar tetap masuk melalui situs belajar, bukan melalui berkas JSON atau CSV.

Skema generik adapter jalur 2.3.1 — diterima untuk B10, D60, dan D110

Enam skema berikut bersifat netral-korpus dan memvalidasi adapter B10 v0.2.0, D60 v0.1.0, serta D110 v0.1.0. B10 menghubungkan 161 unit dan 284 relasi. D60 menghubungkan 27.642 rekaman kanonik kepada 8.338 rekaman native pemilik. D110 menghubungkan 41.460 rekaman kanonik, 9.272 pemetaan native reversibel, dan 19 tabel JSONL/CSV kepada 10.978 rekaman native pemilik. Ketiganya mempertahankan status terjemahan, hak komponen, aksesibilitas, dan lintas-jalan namespace tanpa menyalin isi buku.
