Skema backend modular v2.3

Batas cakupan: adapter A00 + O001 v0.1.0, B10 v0.2.0, paket Judson bersama C30/C40, Open Logic C80, Riset Operasi C130, D20 v0.1.0, D60 v0.1.0, dan D110 v0.1.0 memberi sembilan ikatan peran melalui delapan paket serta mempertahankan backend native sumber secara zero-copy. Bukti ini tidak menyatakan konformansi untuk 31 peran lain. Paket A00 lama v0.1.1 tetap publik sebagai bukti pendahulu. Pelajar masuk melalui situs belajar—termasuk Latihan & diagnosis A00, peta C30, peta C40, pembaca C80, dan pembaca C130—bukan melalui berkas JSON atau CSV.

Skema generik adapter jalur 2.3.1 — diterima untuk A00, B10, C30, C40, C80, C130, D20, D60, dan D110

Enam skema berikut bersifat netral-korpus dan memvalidasi delapan paket yang mengikat sembilan peran. A00 memakai ulang spine 1.313 rekaman dan merujuk 24.315 rekaman asesmen native melalui sidecar khusus, dengan 21.450 jangkar HTML terverifikasi serta nol asesmen yang dipromosikan sebagai unit kurikulum. B10 menghubungkan 161 unit dan 284 relasi. Paket Judson bersama memproyeksikan 15 bab C30 dan 8 bab C40 dari satu graf dengan 23 sambungan native dan tanpa unit duplikat. C80 mengikat 722/722 identitas sumber-terjemahan Open Logic; C130 memproyeksikan 51.704 rekaman kanonis dan tujuh rute publik. D20 menghubungkan 138.894 rekaman kanonik melalui 32.383 pemetaan native reversibel. D60 menghubungkan 27.642 rekaman kanonik kepada 8.338 rekaman native sumber. D110 menghubungkan 41.460 rekaman kanonik kepada 10.978 rekaman native sumber. Kesembilan ikatan mempertahankan status terjemahan, hak komponen, aksesibilitas, dan lintas-jalan namespace tanpa menyalin isi buku.
