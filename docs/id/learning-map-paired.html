Tombol bahasa memakai berkas lokal. Pertahankan susunan folder setelah mengekstrak ZIP. Browser dapat menyimpan catatan terpisah untuk tiap berkas; gunakan unduh/pulihkan catatan untuk memindahkannya.

Kemajuan saya —

Catatan disimpan hanya di browser ini, tidak dikirim ke server. Bahasa yang berbeda memakai catatan yang sama pada situs ini. Ini catatan pribadi, bukan sertifikasi.
