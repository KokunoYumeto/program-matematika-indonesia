Reading with context

The edition
is part of the work.

This library connects existing reading homes. It keeps study programs, course readers, collected works and reference editions distinct, while making it easier to move between them.

Language and register belong to each work; program interface language is recorded separately from text language. A published English edition does not imply an Indonesian translation, and a reserved entry does not imply a finished text. Drafts retain their draft status; original works and translations remain separately identified.

AI-generated or unofficial material is labeled as such. A link to a reader confirms a reading route, not mathematical completeness or editorial endorsement.
