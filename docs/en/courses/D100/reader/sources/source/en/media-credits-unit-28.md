# Media credits for Unit 28 {#agc-media-credits-unit-28}

Lecture 28 contains four substantive reader media positions. Worksheet
28 and its public solution contain no additional media. All reader files
below are byte-identical copies of the frozen Commons originals; an
additional witness copy of each file is stored in
`authority/wikiversity/unit-28/assets/`.
The two official upstream PDFs are visual/build authority witnesses,
not reader media positions.

   The older inline course credit names user Ranveig and the label PD;
