[Download the complete offline reader and original source](https://github.com/KokunoYumeto/program-matematika-indonesia/releases/download/v0.63.28/A30-Precalculus-2e-original-English-reader-source-v1.zip) (107.4 MB). Extract the ZIP and open `START-HERE.html`. The [preserved program version](https://doi.org/10.5281/zenodo.22651565) includes this package and the expanded offline curriculum.

All 87 original English modules are included, with 26,583 MathML expressions,
7,250 exercises, 4,183 source-provided solutions, and 1,873 original image
files. Solutions can be expanded where they occur; the whole-book view opens
all of them. No missing answers have been invented.

The book text, mathematics, styles, and figures work locally after downloading
the complete reader. Publisher services and links to external websites still
require an internet connection. Each page links to its contents, the program,
and the original publisher.

contributors. OpenStax publishes the book under CC BY-NC-SA 4.0. Original
figures, captions, and contributor credits are retained; third-party material
remains subject to its credited source terms. Separate image licenses have
not been independently verified for every component. This independent,
noncommercial mirror is not endorsed by OpenStax or its contributors.

This is a presentation of original English, not a translation. The source is
frozen at OpenStax commit `789b54099106b071d1d32bfcee454fed72eb4768`.
Changes concern HTML structure, navigation, expandable solutions, and
source-grounded presentation labels. Legacy unitless column widths are retained
as metadata without guessing their units. One outside-collection “Complex
Numbers” link is directed to the publisher's current topic page, with the old
source identifier retained in the link metadata. Mathematical source bytes
are unchanged.
