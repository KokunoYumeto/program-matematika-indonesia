Principle 3.3.1. Sum Principle (with sets).

Given two sets \(A\) and \(B\text{,}\) if \(A \cap B = \emptyset\text{,}\) then
\begin{equation*} \card{A \cup B} = \card{A} + \card{B}\text{.} \end{equation*}
