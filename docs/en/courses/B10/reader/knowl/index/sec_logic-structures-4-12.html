The proof of Proposition 1.5.3 is what is sometimes called an element chasing proof. By the definition of subset, \(A \subseteq B\) means every element of \(A\) is an element of \(B\text{,}\) or equivalently, for all \(x\text{,}\) if \(x\) is an element of \(A\text{,}\) then \(x\) is an element of \(B\text{.}\) One way to prove this is to “chase” the element \(x\) from \(A\) to \(B\text{.}\)
