There is one more important consideration about how we define a function with a rule. A closed formula is one in which each output is given by an explicit rule based solely on its input. This is what most of us think of as a formula. For example, \(f(n) = 3n + 1\) is a closed formula, since to find \(f(5)\) (say) we take the input 5 and do something to it: Multiply it by 3 and then add 1.
