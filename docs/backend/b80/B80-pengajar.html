Prasyarat inti dan pengayaan

B80 dimulai setelah A30. 3 jalur tambahan memakai materi B30, B40, B70; jalur tersebut tidak menjadi syarat untuk menyelesaikan inti B80.

  • Jalur inti A30/B80: metode, bagi-dua, SciPy, dan sumber galat — inti B80; prasyarat A30.
  • Jalur B30: kuadratur — pengayaan, bukan syarat penyelesaian B80; prasyarat B30.
  • Jalur B40: sistem linear — pengayaan, bukan syarat penyelesaian B80; prasyarat B40.
  • Jalur B70: langkah Euler — pengayaan, bukan syarat penyelesaian B80; prasyarat B70.
