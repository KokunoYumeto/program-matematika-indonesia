# Permanent PDF accessibility disclosure

This text is the permanent public disclosure required by the complete audit in
`qa/PDF_FONT_AND_TAG_AUDIT_2026.08.24.json`. It does not claim tagged-PDF or
PDF/UA conformance.

## Indonesian

> **Aksesibilitas PDF.** PDF ini adalah edisi cetak berhalaman tetap dan belum
> memiliki tag struktur PDF. Teks dapat dicari dan disalin, dan penanda bab
> tersedia, tetapi urutan baca, judul, daftar, tabel, rumus, dan tautan belum
> dikodekan sebagai struktur semantik untuk teknologi bantu. PDF ini tidak
> dinyatakan memenuhi PDF/UA. Untuk pembacaan dengan pembaca layar,
> pembesaran/reflow, navigasi papan ketik, dan struktur MathML, gunakan edisi
> HTML semantik yang diterbitkan bersama edisi ini.

## English

> **PDF accessibility.** This fixed-layout print PDF is currently untagged. Its
> text is searchable and chapter bookmarks are present, but reading order,
> headings, lists, tables, mathematics, and links are not encoded as an
> assistive-technology structure. No PDF/UA conformance is claimed. Use the
> companion semantic HTML edition for screen readers, keyboard navigation,
> reflow/zoom, and MathML.

## Placement rule

Publish both paragraphs beside every PDF download and in the PDF-facing README
or landing page. Retain them until a later PDF is independently proven to have
a valid structure tree, correct reading order, tagged links/tables/mathematics,
and an accessibility QA result. Searchable text and bookmarks alone are not a
basis for removing the disclosure.
