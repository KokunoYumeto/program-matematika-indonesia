# D10 — Fondasi Teori Ukuran

Pembaca HTML lengkap untuk adaptasi Bahasa Indonesia dari *Measure Theory*,
Jilid 1–2, karya D. H. Fremlin tersedia di [`reader/index.html`](reader/index.html).
Pembaca ini mencakup 672/672 halaman resmi, 94 unit, 1.096 latihan tertipe
(1.094 bertajuk standar dan 2 bertajuk varian), serta 276 petunjuk eksplisit.
Seluruh CSS, MathJax, font, gambar, dan PDF unduhan
yang diperlukan untuk membaca secara luring disimpan bersama pembaca.

Sumber publik dan bentuk sumber yang dapat disunting tetap tersedia di
[repositori edisi](https://github.com/KokunoYumeto/fremlin-measure-theory-id),
[rilis v1.0.0](https://github.com/KokunoYumeto/fremlin-measure-theory-id/releases/tag/v1.0.0),
dan [rekaman Zenodo](https://zenodo.org/records/22181780).

Salinan ini tidak mengubah byte isi pembaca. Inventaris sumber-ke-cermin,
hash SHA-256, pemeriksaan tautan lokal, dan batas lisensi komponen dicatat di
`D10_READER_MIRROR_MANIFEST_V1.json` dan `D10_READER_MIRROR_RECEIPT_V1.json`.
Lihat [`RIGHTS_AND_ATTRIBUTION.md`](RIGHTS_AND_ATTRIBUTION.md) sebelum
mendistribusikan ulang atau memodifikasi materi.
