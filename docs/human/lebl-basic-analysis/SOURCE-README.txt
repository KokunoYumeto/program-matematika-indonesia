html/ contains the complete static web reader; serve that directory with any static HTTP server. Web mathematics uses MathJax 3.2.2 from jsDelivr and needs a network connection.

tex/ contains the author’s modular LaTeX and required book figures. realanal.tex builds volume I, realanal2.tex volume II, and realanal12.tex both volumes. Use a full TeX distribution, latexmk -pdf, and makeglossaries as required by the author’s preamble. basic-analysis-6.3.tex is the combined editable file; figures/ and vogtwidebar.sty are supplied in tex/. Put it beside those files to compile it.

The mathematical text is Jiří Lebl’s work. HTML navigation and presentation adapted with OpenAI Codex — GPT-6 Astra, Ultra effort, and GPT-6.1 Sol, Ultra effort.
