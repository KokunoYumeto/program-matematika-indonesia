The Science of Computing (The Art of HPC, volume 1)

Victor Eijkhout’s textbook on the computational side of scientific computing: how processors and memory shape a computation, parallel computing, floating-point arithmetic and round-off, finite-difference methods for differential equations, and direct and iterative methods for linear systems, including conjugate gradients, GMRES and preconditioning.

Before you start

Bring linear algebra (B40 — Linear Algebra) and calculus. Chapter 14 reviews the linear algebra the book uses and chapter 16 the background on partial differential equations. Some programming experience helps; the book contains code examples and class projects.

How it fits C110

C110 — Numerical Analysis teaches approximation, linear systems, interpolation, numerical calculus and differential equations from Leon Brin’s Tea Time Numerical Analysis. This book adds what numerical analysis courses often leave to computing courses: how floating-point numbers behave and how round-off errors arise (chapter 3); how finite-difference discretizations of ordinary and partial differential equations lead to large sparse linear systems (chapter 4); how such systems are solved by direct and iterative methods, including conjugate gradients, GMRES and preconditioners (chapter 5); and how this is done efficiently on real machines (chapters 1, 2, 6 and 7).
