Before you start

Bring basic programming experience with arrays, loops, methods, classes, references and recursion. The implementations use Java. Chapter 1 introduces asymptotic notation, probability and the computation model.

B10 — Discrete Mathematics supplies preparation in reasoning and proof. B80 — Mathematical Computing supplies programming and reproducible-experiment practice in Python and SageMath; it is not an introductory Java course.

Follow the author’s chapter order; Section 1.7 explains the chapter dependencies. This book supplies a data-structures foundation, not a complete general algorithms course.

For educators

Each chapter has discussion and exercises. Combine reading the arguments with implementing operations, testing boundary cases and comparing measured performance with the complexity bounds. The author’s Java code is in the source ZIP. A complete solutions manual is not included.
