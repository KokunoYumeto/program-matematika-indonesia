Open Data Structures (in Java)

Buku Pat Morin tentang struktur data: implementasi Java, analisis waktu dan ruang, pembuktian, contoh, serta latihan. Keempat belas bab mencakup daftar, tabel hash, pohon pencarian, heap, pengurutan, graf, dan pencarian dalam memori eksternal.

Buku lengkap ini berbahasa Inggris: edisi 0.1G, 334 halaman. Halaman ini menyediakan navigasi berbahasa Indonesia; judul bab mengikuti buku aslinya.

Persiapan belajar

Siapkan dasar pemrograman: larik, perulangan, metode, kelas, referensi, dan rekursi. Implementasi dalam buku menggunakan Java. Bab pertama membahas notasi asimtotik, probabilitas, dan model komputasi.

B10 — Matematika Diskrit membantu persiapan penalaran dan pembuktian. B80 — Komputasi Matematis menyediakan latihan pemrograman dan eksperimen yang dapat direproduksi; materi pemrogramannya menggunakan Python dan SageMath, bukan kursus pengantar Java.

Bacalah menurut urutan bab penulis; Bagian 1.7 menjelaskan hubungan antarbab. Buku ini menyediakan landasan struktur data, bukan keseluruhan kursus algoritma umum.
