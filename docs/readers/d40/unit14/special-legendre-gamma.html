Fungsi Gamma

Fungsi gamma diperlukan untuk mendefinisikan fungsi-fungsi Bessel pada bagian berikutnya. Penggunaan fungsi gamma dalam matematika tidak terbatas pada definisi fungsi-fungsi Bessel. Bahkan, fungsi gamma muncul di banyak bidang matematika. Fungsi gamma memainkan peranan penting dalam analisis matematika, dalam teori bilangan analitik, dan sebagainya.

Fungsi gamma Γ\Gamma didefinisikan oleh

Γ(ν)=∫0∞e−ttν−1dt\Gamma(\nu) = \int_0^\infty e^{-t} t^{\nu-1} \,\mathrm{d}{t} untuk ν>0\nu > 0 dan secara rekursif oleh Γ(ν)=Γ(ν+1)/ν\displaystyle\Gamma(\nu) = \Gamma(\nu + 1)/\nu untuk ν<0\nu < 0, dengan ν\nu bukan bilangan bulat negatif.
