Pemisahan Variabel

Pada bagian ini, kita menggunakan metode pemisahan variabel untuk menyelesaikan persamaan gelombang dengan beberapa syarat awal dan syarat batas.

Metode pemisahan variabel secara umum dapat digunakan untuk mencari solusi kuat persamaan gelombang. Kita akan kembali membahas topik ini nanti. Teorema berikut menyatakan bahwa jika syarat awal cukup mulus, maka metode pemisahan variabel menghasilkan solusi klasik.
