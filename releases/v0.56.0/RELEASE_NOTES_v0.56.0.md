# Program Matematika Indonesia v0.56.0

Rilis ini adalah snapshot pusat yang dapat direproduksi untuk program matematika terbuka berbahasa Indonesia. Pintu masuk untuk pelajar adalah situs HTML:

<https://kokunoyumeto.github.io/program-matematika-indonesia/>

Arsip Zenodo menyediakan PDF/HTML mulai-belajar terlebih dahulu, lalu katalog, sumber, dan backend sebagai artefak sekunder untuk pengindeksan mesin dan reproduksibilitas.

## Perubahan utama

- Mempertahankan peta 40 peran kurikulum dan enam belas DOI edisi publik yang memetakan tujuh belas peran selesai.
- Mempertahankan C100, *Bidang Euklides dan Kerabatnya*, sebagai kursus utama lengkap yang bersih hak (DOI `10.5281/zenodo.22102628`); workbook Clemens/Snapp yang berlisensi berbeda tidak dicampurkan.
- Menambahkan federasi modular v2.1 sebagai pilot tervalidasi untuk A00, B10, dan D20 (255 unit, 1.171 relasi).
- Menambahkan rute HTML pembungkus D20 yang learner-facing; JSON dan paket backend tetap menjadi antarmuka mesin sekunder.
- Menyimpan riwayat otoritas v0.55.0 dan successor v0.56.0 secara byte-terikat.

Snapshot ini tidak menyatakan seluruh terjemahan selesai. Peran yang masih diproduksi, helper yang belum diintegrasikan, dan batas hak/format tetap diberi status eksplisit dalam katalog.

Provenance engineering: OpenAI Codex gpt-5.6-sol, Ultra, atas instruksi pengguna; kredit penulis, sumber, lisensi, dan kontributor manusia tetap dipertahankan pada setiap komponen.
