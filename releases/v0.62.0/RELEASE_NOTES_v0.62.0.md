# Program Matematika Indonesia v0.62.0

Mulai belajar melalui situs siswa:
https://kokunoyumeto.github.io/program-matematika-indonesia/

Rilis korektif ini memperbarui katalog pusat agar mengikuti edisi pemilik yang
sudah terbukti publik:

- 21 dari 40 peran mata kuliah kini memiliki edisi lengkap publik pada 20
  rekaman edisi berbeda.
- B20 Kalkulus Diferensial memisahkan buku teks 442 halaman dan buku soal serta
  penyelesaian 646 halaman.
- D90 Optimisasi Lanjut menunjuk edisi terminal lengkap 141 halaman dan bukan
  lagi checkpoint parsial lama.
- A10 tetap berstatus produksi pada checkpoint publik 32/82 modul dan 1.011
  halaman; rilis ini tidak mengubahnya menjadi buku lengkap.
- B40 memisahkan buku teks, jawaban bekerja, dan laboratorium Sage sebagai tiga
  bahan belajar yang dapat dibuka sendiri-sendiri.
- A30 memperoleh rute repositori publik; D80 tetap produksi pada Unit 050 dan
  menambahkan D70 sebagai prasyarat langsung.
- Situs menambahkan catatan penyelesaian, penempatan, kesetaraan, dan waiver
  khusus sisi-prasyarat. Semua data tinggal di browser dan tidak dikirim.
- Federasi v0.4.4 memuat 2.490 rekaman: 34 dataset, 40 mata kuliah, 164
  permukaan baca, 43 rute web, 2.122 crosswalk identitas, 69 peristiwa
  publikasi, dan 17 peristiwa QA.

Program keseluruhan belum lengkap. Kartu mata kuliah tetap membedakan edisi
lengkap dari checkpoint produksi. Backend JSON/CSV tersedia untuk mesin, tetapi
situs siswa, HTML mandiri, dan PDF “Mulai Belajar” adalah pintu masuk manusia.

Koordinasi, rekayasa backend, dan QA rilis dibantu oleh OpenAI Codex
gpt-5.6-sol, Ultra atas instruksi pengguna. Kredit serta lisensi setiap karya
tetap mengikuti edisi pemiliknya.
