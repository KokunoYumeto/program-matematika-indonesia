<https://kokunoyumeto.github.io/program-matematika-indonesia/>

Pilih titik mulai, ikuti prasyarat, lalu buka edisi HTML atau PDF dari kartu
mata kuliah. Di arsip Zenodo, buka
`00_MULAI_BELAJAR_PROGRAM_MATEMATIKA_INDONESIA_v0.51.1.html` untuk salinan
HTML mandiri. Berkas JSON, schema, CSV, dan ZIP backend adalah lapisan mesin.

## Perubahan patch

- Menjadikan URL situs belajar sebagai URL kanonis dan aksi publik utama.
- Menempatkan HTML mandiri berawalan `00_MULAI_BELAJAR` sebelum berkas backend
  dalam inventaris Zenodo.
- Menambahkan tautan situs belajar secara eksplisit ke README, catatan rilis,
  dan metadata Zenodo.
- Mengangkat 12 pembaca HTML publik yang sudah diverifikasi menjadi aksi utama
  pada kartu mata kuliah; PDF/edisi, DOI, repositori, dan backend tetap tersedia
  sebagai tautan sekunder.
- Mempertahankan status kurikulum, pilihan korpus, dan hitungan penyelesaian;
  metadata backend kini menunjuk pembaca/edisi sebagai `official_reader`,
