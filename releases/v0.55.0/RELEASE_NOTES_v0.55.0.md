# Program Matematika Indonesia v0.55.0

**Situs untuk pelajar:**
<https://kokunoyumeto.github.io/program-matematika-indonesia/>

Pilih titik mulai, ikuti prasyarat dan petunjuk **Lanjut ke**, lalu buka
pembaca HTML atau PDF dari kartu mata kuliah. Zenodo menampilkan
`00_MULAI_BELAJAR_PROGRAM_MATEMATIKA_INDONESIA_v0.55.0.pdf` sebagai lembar
mulai-belajar manusia. Salinan HTML mandiri adalah
`01_MULAI_BELAJAR_PROGRAM_MATEMATIKA_INDONESIA_v0.55.0.html`.

## Perubahan

- Mengakui C100 Geometri sebagai kursus utama lengkap dan terverifikasi
  publik pada DOI `10.5281/zenodo.22102628`: tulang punggung Petrunin yang
  bersih hak, 253 solusi, pendamping konektif enam unit beserta solusi, empat
  pemeriksaan kumulatif, dua capstone, backend, HTML semantik, dan EPUB.
- Mempertahankan workbook Clemens/Snapp dalam lini terpisah sesuai lisensinya;
  workbook itu tidak dicampurkan ke rilis kursus utama CC BY-SA 4.0.
- Menaikkan keadaan publik menjadi 17 peran mata kuliah pada 16 rekaman edisi
  berbeda. C30 dan C40 tetap berbagi satu edisi Judson.
- Menaikkan federasi ke v0.3.0: 2.434 rekaman, 128 permukaan baca, dan 52
  peristiwa publikasi. Dua permukaan serta dua peristiwa baru mengikat PDF dan
  DOI O004; identitas v1 dan semua backend native pemilik tetap tidak berubah.
- Menambahkan overlay readback anonim ketiga sehingga permukaan utama C100
  menjadi efektif publik di model-baca pelajar tanpa menulis ulang bukti
  historis federasi.
- Memperbaiki provenance federasi agar bukti readback pusat yang diwarisi
  tidak pernah diberi label versi kandidat baru secara keliru.
