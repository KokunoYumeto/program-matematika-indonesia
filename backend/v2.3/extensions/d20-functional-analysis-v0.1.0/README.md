# D20 functional-analysis adapter v0.1.0

This directory publishes the compact authority surface for the admitted D20
adapter: its input bindings, capability and scope declarations, projection
manifest, package manifest, checksum inventory, and seal.

The complete deterministic package is distributed as
`program-matematika-indonesia-backend-v2.3.1-d20-adapter-v0.1.0.zip` in central
release `v0.62.12` and in the matching version of Zenodo concept DOI
`10.5281/zenodo.22059707`. The ZIP is 61,438,875 bytes with SHA-256
`25e059d26f049141dad326817bd01319b120a19fc4b78fb2efc879764fea2099`.
It contains 61 files and 551,281,460 uncompressed bytes. The Git tree does not
duplicate the large table payloads, including the 183,220,480-byte global CSV;
their exact names and hashes remain bound by `PACKAGE_CHECKSUMS.sha256`, the
manifest, and the sealed release archive.

The adapter preserves the owner backend rather than replacing it. It exposes
138,894 canonical records, 32,383 reversible native mappings, 2,104 additional
index rows, and 19 lossless JSONL/CSV table pairs. Learners should use the D20
HTML course route; this directory and the release archive are machine and
reproducibility surfaces.
