Retrospective contextual examination, 8 September 2026. This supplements the
UAD witness packet; it does not revise a textbook or complete the terminology
review of a course.

page-addressed extraction. Definition 1.13 (printed page 24) uses B90's existing
conditional-probability designation for the intersection-to-conditioning-event
probability ratio, with a positive denominator. The next page applies the
definition in both directions of an aircraft example and in a die example.
Conditioning is therefore not limited to an event occurring later in time.

Together with UAD Definition 1.3, this establishes contextual scholarly support
for both existing B90 and D30 designations. A different lexical root is not, by
itself, evidence that either translation is wrong. A program-wide preferred
form or register distinction has not been established by these two sources.

implies about impossibility; that mathematical claim is not imported.
