# D10 common capability adapter

Zero-copy projection of the complete public O007/Fremlin Volumes I–II backend into `course-learning-capability/1`. It preserves 94 ordered unit identities, 1,096 typed exercise IDs, 276 explicit source hints, 53,491 formula occurrences, 420 correction rows, 132 structured terminology decisions, all 506 catalog-manifest members, and the exact GitHub/Zenodo release lineage.

The learner view provides searchable unit/source/archive navigation. The educator view exports selected native unit and exercise identities. No native bodies, outcomes, per-unit prerequisites, learner records, complete solutions, online-native-HTML claim, tagged-PDF claim, or blanket license are created.
