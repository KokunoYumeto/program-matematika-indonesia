# D70 thin capability adapter

This adapter federates the four native O013 components without copying their book bodies. It preserves native identities, component rights, source locales, exact selection boundaries, route dependencies, diagnostic/mastery provenance, terminology state, correction records, public byte identities, and explicit accessibility/replay limits.

Learners receive a seven-stage route, staged diagnostics/mastery support, four public reader destinations, and a searchable 54-root catalog. Educators receive the same route identities plus dependency, answer, policy, correction, terminology, rights, and evidence views.

The adapter does **not** claim native HTML, EPUB, MathML, tagged PDF, complete ToUnicode, WCAG conformance, assistive-technology testing, PDF byte replay, or a complete native roundtrip.
