# D20 native study and teaching tools

This consumer makes the existing Functional Analysis backend usable for reading,
exercise selection and reusable teaching plans. It preserves 1,960 native unit
records, their source metadata and component rights, and 184 explicit support
relationships. Every unit has an exact unique destination in the existing
Indonesian source or companion readers. No textbook body is copied or rewritten.

The 52 exercise solutions and ten selected reader-work proofs are separately
authored companions, not Erdman's original solutions. Each historical queued
exercise-support row is retained alongside its exact hash-bound admitted status
overlay. The 13 compact-spectral/SVD bridge units preserve five native chapter
prerequisites. The historical queued bridge-planning row is preserved separately
from the admitted companion component; it is not used as current production state.

The 15 concepts and six concept prerequisites describe Chapter 1 only. They are
not a complete course concept graph or exercise-level diagnostic map. The older
external COURSE-O007 relation is retained without guessing a modern course ID.

## Reproduce

Run `npm run build:d20-surface` to replay the projection, independent tests and
scoped admission. Ordinary replay uses committed metadata and route witnesses,
without network access or an external producer checkout. The common navigation
overlay and shared interface build are applied afterwards. Generated raw view
hashes and final hosted-view hashes therefore have deliberately separate roles.

For an intentional source refresh only, use
`python -B scripts/intake-d20-surface-v1.py --native-root PATH`. Intake verifies
the existing admission bindings and anonymously compares all 37 registered
public HTML pages with exact native bytes. It freezes metadata and 5,132 route
witnesses, not the reader bodies. Producer files are read-only.

Fourteen negative fixtures reject stale status bindings, ambiguous destinations,
missing support endpoints, unknown rights and other identity damage. Independent
tests preserve every projected native record and support relationship, check
selection/export behavior, and compare two builds with the canonical output.
Browser checks and an actual exported-plan comparison are recorded separately.

## Scope

The learner and teacher interfaces are Indonesian/English; linked content is
Indonesian. This is not an everyday-English edition. Selected plans contain
metadata, provenance and links, not full offline textbooks. No selections are
stored or transmitted, and no new answers are generated. Teacher alignment is
exact unit/support selection, not a new syllabus, grading system or complete
native production/accessibility audit. Full forty-role backend completion is
still a separate, unfinished objective.
