# Geometry learning capability — C100

Contract: `geometry-learning-capability/1`. This is not a claim that the entire
40-role backend, the native book production pipeline, or a generic format
roundtrip is complete.

The adapter reuses the existing 939-unit C100 pilot and the unchanged complete
reader. It exposes native concepts/prerequisites, contextual terminology,
figure descriptions, correction records and source-specific rights. Learners
follow the same stable identities used in the local teacher activity planner.

The create-once input contains all 26 selected native metadata files without
field rewriting. `input/source-lock.json` records their exact bytes/hashes,
the 96 existing pilot/native bindings checked at intake, and unchanged central
dependencies. Original production sources remain outside this adapter.

Reproduce and validate from the program repository:

```text
python -B scripts/build-geometry-capability-v1.py
python -B scripts/validate-geometry-capability-v1.py
```

The validator independently compares all projected native fields, support
relationships, the 994-edge concept graph, source destinations and teacher
selections; rejects deliberate mutations; tests the shipped controls without
a browser; and compares two isolated builds byte-for-byte. Source reader hashes
are fixed. Validation is not a new language, mathematical or accessibility
certification of the source books.

Native concept states remain 18 admitted, 125 mapped-admitted and 348
mapped-pending-qa. Three concepts use an evidenced Chapter 8 fallback, not an
invented exact anchor. Of 214 figure metadata records, one is explicitly
source-disabled. Context notes are not treated as accepted synonyms. The 285
exercise surfaces include 253 parent exercises and 32 subparts. Independently
authored solutions retain their separate provenance and shared complete PDF;
no exact solution-page destination is invented.

The main course and separately licensed Clemens/Snapp workbook remain distinct.
No book/figure/reference payload is removed, privatized or newly copied because
of a historical rights label. Full input metadata is retained for traceability.
The source book is Anton Petrunin's *Euclidean Plane and Its Relatives*, with
component-specific rights carried in the source/pilot records. Integration
and navigation changes: OpenAI Codex gpt-5.6-sol, Ultra.
