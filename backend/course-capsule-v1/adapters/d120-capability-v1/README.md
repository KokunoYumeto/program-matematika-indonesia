# D120 common capability adapter

This is a zero-copy projection of the native O017/D120 backend into `course-learning-capability/1`. It preserves native IDs, separates the 1,107-row base relation ledger from the 1,704-row semantic-wrapper ledger, and gives learners and educators shared unit, outcome, exercise, guidance, assessment, rubric and evidence identities. Course prose, source files, PDFs and archives remain in the native public edition.

No learner attempt, submission, result, external participation or credential is claimed. HTML fragments are locators only. Rights remain component-specific.
